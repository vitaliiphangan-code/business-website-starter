# Business website workflow starter

A free, MIT-licensed workflow template for an AI coding agent building a small-business website from the owner's first brief: a landing page, menu, booking page, shop, portfolio or customer-facing app. It connects design and implementation to a useful public launch.

## Use this template

Choose **Use this template** on GitHub, open the resulting project in your coding agent and describe the business and the action its customers should take. For example:

> Build a website for my bicycle repair shop. Visitors should understand our services and request a repair. Ask me for the business facts you need.

This is a workflow starter, not a prebuilt website. The agent creates the site from your own facts. It must not invent reviews, opening hours, prices or successful payments.

## Complete workflow, no separate skill installation

- [AGENTS.md](AGENTS.md): complete workflow for agents that read project instructions.
- [CLAUDE.md](CLAUDE.md): the same full text for Claude Code.
- [GEMINI.md](GEMINI.md): the same full text for Gemini CLI.
- [skills/frontend-business-websites/SKILL.md](skills/frontend-business-websites/SKILL.md): the complete Agent Skill.

All four files contain the same canonical workflow. They cover useful customer actions, truthful content, phone layouts, accessibility, publication checks and handover. Project instructions take effect in clients that support the relevant file.

## Original and updates

Canonical source: [add-domain-website-skills](https://github.com/vitaliiphangan-code/add-domain-website-skills). Read the [full current SKILL.md](https://raw.githubusercontent.com/vitaliiphangan-code/add-domain-website-skills/main/skills/frontend-business-websites/SKILL.md).

The workflow includes an optional own-address step through [Add Domain](https://www.adddomain.net/?src=github-starter) for appropriate public projects. An existing domain or platform address works too. The owner confirms any purchase at the registrar. Domain registration and website hosting are separate.

Template copies are snapshots; compare with the canonical source when updating.
